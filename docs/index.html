otop

htop/btop for Odoo — version 1.0.1.

Install

curl -fsSL https://raw.githubusercontent.com/ahmedsajidh/otop/main/docs/install.sh | sudo sh
sudo apt install otop

Or add the repository by hand

sudo curl -fsSL https://raw.githubusercontent.com/ahmedsajidh/otop/main/docs/otop-archive-keyring.gpg -o /usr/share/keyrings/otop-archive-keyring.gpgsudo curl -fsSL https://raw.githubusercontent.com/ahmedsajidh/otop/main/docs/otop.sources -o /etc/apt/sources.list.d/otop.sources
sudo apt update && sudo apt install otop

Upgrades

sudo apt update && sudo apt upgrade otop
